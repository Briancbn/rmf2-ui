# RMF2 UI

## Setup Instructions

Install `pnpm`, and node

```bash
curl -fsSL https://get.pnpm.io/install.sh | sh -
source ~/.bashrc
pnpm env use --global 22
```

Install dependencies

```bash
pnpm install
```

## Quick start

Serve the dashboard

```bash
pnpm start
```

## Usage Instructions

Build the necessary packages live

```bash
pnpm chakra build --watch
```

Launch the dashboard

```bash
pnpm app dev
```
