# RMF2 UI

## Setup Instructions

Install `pnpm`, and node

```bash
curl -fsSL https://get.pnpm.io/install.sh | sh -
source ~/.bashrc
pnpm env use --global 20
```

Install dependencies
```bash
pnpm install
```

## Usage Instructions

Run the dashboard.
```bash
pnpm start
```

You can also choose to create a production build.

```bash
pnpm build
```

Preview production build

```bash
pnpm preview
```
